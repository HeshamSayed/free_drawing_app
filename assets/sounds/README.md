# Sound Effects

Add the following MP3 sound effect files to this directory:

- `brush_stroke.mp3` - Played when drawing
- `success.mp3` - Played when saving a drawing
- `click.mp3` - Played on UI interactions
- `unlock.mp3` - Played when unlocking content

You can find free sound effects at:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

The app will work without sound effects (audio is optional and can be disabled in settings).
