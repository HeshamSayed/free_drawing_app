# Animations

Add Rive (.riv) or Lottie (.json) animation files here for enhanced UI effects.

Suggested animations:
- `welcome.riv` - Welcome screen animation
- `drawing.riv` - Drawing canvas animation
- `success.riv` - Success celebration animation
- `unlock.riv` - Unlock effect animation

Free animation resources:
- https://rive.app/community/
- https://lottiefiles.com/

The app will work without animations (they are optional enhancements).
