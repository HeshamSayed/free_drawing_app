# Changelog

All notable changes to ArtJoy will be documented in this file.

## [1.0.0] - 2024-11-10

### Added
- ✨ Initial release of ArtJoy - Free Drawing & Coloring Game
- 🎨 Advanced drawing engine with 6 brush types (Pen, Marker, Pencil, Neon, Watercolor, Eraser)
- 🌈 Rich color picker with 20+ preset colors and custom color selector
- 📏 Adjustable brush size (1-50px) and opacity controls
- 🔄 Undo/Redo functionality with full history
- 👆 Zoom and pan support for canvas
- 💾 Local offline storage using Hive database
- 🖼️ Gallery screen for managing saved drawings
- 🎨 8 coloring pages (3 free, 5 unlockable with rewarded ads)
- 🌓 Dark and light theme support
- 🔊 Optional sound effects
- 📱 Responsive UI for phones and tablets
- 💰 Smart AdMob integration (Banner, Interstitial, Rewarded)
- 💎 Premium upgrade option
- ⚙️ Settings screen with preferences
- 📊 Drawing statistics tracking
- 🔍 Search functionality in gallery
- 🎯 Achievement system foundation
- 📤 Share functionality
- ✅ Android and iOS support

### Technical
- Clean architecture with proper separation of concerns
- Provider for state management
- Hive for local database
- Google AdMob SDK integration
- Performance optimized drawing engine
- Comprehensive test coverage
- Full offline support

### Configuration
- AdMob App ID: ca-app-pub-6976864649919972~8450614936
- Min SDK: Android API 21, iOS 12.0
- Target SDK: Android 34
